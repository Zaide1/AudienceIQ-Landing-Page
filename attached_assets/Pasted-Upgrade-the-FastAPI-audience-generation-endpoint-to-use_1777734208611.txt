- region must reflect finalRegion.
- category must reflect finalCategory.
- confidence must be "Low", "Medium", or "High".

- coverage.percent must be a number.
- coverage.people must be a number.
- untapped.percent must be a number.
- untapped.min and max must be numbers.
- segments must contain exactly 5 objects.
- Segment percentages must sum to exactly 100.
- Segment colors must be exactly, in this order:
  1. purple
  2. blue
  3. green
  4. orange
  5. pink
- Each segment must include:
  - id
  - name
  - percent
  - audienceMin
  - audienceMax
  - color
  - painPoints
  - platforms
  - whyThisSegment
  - acquisitionAngle
- insights must contain exactly 3 objects.

Validation/normalisation:
